Qué vas a construir hoy

En la Semana 12 conectaste un servidor MCP remoto (Context7). Hoy construiste la otra cara: un servidor MCP propio que expone datos de CaribeMart y que opencode usa como anfitrión. La regla de la semana: el modelo propone, tu servidor ejecuta y tú verificas.

  • Un servidor MCP en Node.js con el SDK oficial y validación zod, en Windows.
  • Tres herramientas: consultar_pedido (te la damos), listar_pedidos_por_estado y crear_pedido (las agregas tú).
  • Registro vigente en opencode.json (mcp.servers tipo local), verificado con opencode mcp list.

Diagrama: elaboración propia.

Esta actividad vale 10 % (Corte 3, Actividad 2). Entregas el código con tus 3 herramientas, 3 capturas de opencode llamando cada herramienta y un párrafo sobre qué pasaría sin validación (Paso 10). Ya tienes opencode instalado y el servicio de pedidos de la Semana 12; no reinstalas nada.

La solución completa no está en el repositorio. Aquí solo va el esqueleto con una herramienta. Las otras dos las escribes tú siguiendo el mismo patrón.

1

Paso 1 — Verificar Node.js

Tu servidor MCP está escrito en Node.js, igual que en la Semana 12. No instalas nada nuevo: solo compruebas que Node sigue disponible.

  1. Abre PowerShell: menú Inicio, escribe PowerShell y pulsa Enter. Si ya tenías una ventana abierta, ciérrala y abre una nueva.
  2. Escribe estos dos comandos: 
    node --version
npm --version

Qué debes ver: un número de versión en cada comando (como en la Figura 1 del Laboratorio 6). Cualquier versión LTS reciente sirve.

Si no lo ves: cierra PowerShell, ábrelo de nuevo y repite; si sigue igual, mira “Problemas comunes”.

2

Paso 2 — Descargar el esqueleto y descomprimir

Te damos el esqueleto listo: carpeta mcp-caribemart/ con package.json, server.js (una herramienta) y pedidos.json.

  1. Descarga lab07.zip.
  2. En el Explorador de archivos crea la carpeta C:\caribe\lab07, haz clic derecho sobre lab07.zip → Extraer todo… y elige C:\caribe\lab07. Debe quedar C:\caribe\lab07\mcp-caribemart\server.js.
  3. En PowerShell entra a la carpeta: 
    cd C:\caribe\lab07\mcp-caribemart
  4. Comprueba que están los archivos: 
    dir
    Debes ver server.js, package.json y pedidos.json.

Qué debes ver: la lista con los tres archivos. Aún no existe opencode.json: lo crearás en el Paso 5.

Si no lo ves: escribe dir; los nombres no deben terminar en .txt (mira “Problemas comunes”).

3

Paso 3 — Instalar dependencias

El esqueleto ya declara sus dos librerías en package.json: el SDK oficial de MCP y zod para validar. Instálalas localmente:

npm install

Qué debes ver: mensajes de instalación sin errores y una carpeta nueva node_modules.

Si no lo ves: espera a que termine; si falla por ejecución de scripts, mira “Problemas comunes”.

Nota: no necesitas internet para el servidor en sí: stdio es local. Solo la instalación descarga paquetes.

Abre server.js en el Bloc de notas para ver la herramienta que ya funciona. También abre pedidos.json: allí está el pedido 1001 (Luis, enviado).

5

Paso 5 — Registrar el servidor en opencode.json

opencode descubre tu servidor desde opencode.json en la carpeta del proyecto. Usa el formato vigente (versión 2): los servidores van bajo mcp.servers, no directamente bajo mcp. El ejemplo de Context7 de la Semana 12 usaba otro formato; no lo copies.

  1. En PowerShell, dentro de C:\caribe\lab07\mcp-caribemart, crea el archivo: 
    notepad opencode.json
    Responde Sí para crearlo, pega exactamente este contenido y guarda con Ctrl + S: 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "caribemart": {
        "type": "local",
        "command": ["node", "server.js"]
      }
    }
  }
}

Qué debes ver: el archivo guardado sin errores. Detalles clave: el nombre es caribemart, el tipo es local (stdio) y el comando es una lista con node y server.js. Como opencode arrancará en esta misma carpeta, la ruta relativa funciona.

Nota: en la Semana 12 viste otra forma, con el nombre directamente bajo mcp y enabled. Las dos funcionan en opencode 2; aquí usamos mcp.servers, que es la forma recomendada.

Si no lo ves: comprueba que opencode.json está en la misma carpeta que server.js (no opencode.json.txt) y que abriste opencode desde esa carpeta.

Si quieres otra vista, abre opencode y escribe /mcps: verás el estado y eventuales errores de arranque.

Si no lo ves: revisa la ruta del comando y que hiciste npm install (Paso 3). Abre opencode.json y compara con el Paso 5 letra por letra.

Paso 8 — Agregar listar_pedidos_por_estado (capture 2)

Ahora agregas la primera herramienta propia. Copia el patrón exacto de consultar_pedido en server.js:

  1. Cierra opencode escribiendo /exit (o Ctrl + C dos veces) para editar sin que el servidor esté en uso.
  2. Abre server.js con notepad server.js y, después del bloque de consultar_pedido, pega este bloque nuevo antes de la línea StdioServerTransport:
// Tarea del estudiante 1: listar pedidos por estado.
server.tool(
  "listar_pedidos_por_estado",
  {
    estado: z.enum(["pendiente", "enviado", "entregado", "cancelado"]).describe("Estado permitido"),
  },
  async ({ estado }) => {
    const pedidos = await leerPedidos();
    const filtrados = pedidos.filter((p) => p.estado === estado);
    if (filtrados.length === 0) {
      return { content: [{ type: "text", text: "No hay pedidos con estado " + estado }] };
    }
    const lineas = filtrados.map((p) => "- Pedido " + p.pedidoId + " de " + p.cliente + ": " + p.estado + ", total " + p.total);
    const texto = "Pedidos con estado " + estado + " (" + filtrados.length + "):\n" + lineas.join("\n");
    return { content: [{ type: "text", text: texto }] };
  }
);
  1. Guarda con Ctrl + S, vuelve a ejecutar npm install (no instala nada nuevo, pero confirma) y comprueba con: 
    opencode mcp list
  2. Abre opencode y escribe: 
    Lista los pedidos pendientes de CaribeMart usando mi herramienta

Qué debes ver: una línea con caribemart_listar_pedidos_por_estado y la lista de pendientes (Ana 1002 y Maria 1004, según tu pedidos.json inicial). Esa captura es tu evidencia 2 (evidencia-2-listar.png).

Por qué z.enum: solo acepta los cuatro estados permitidos. Si el modelo inventa otro estado, la llamada se rechaza antes de tocar datos. Cambia el estado a otro valor válido y funciona.

Si no lo ves: si la herramienta no aparece, revisa que guardaste server.js y que cerraste opencode antes de editar.

Paso 9 — Agregar crear_pedido con validación (capture 3)

La segunda herramienta escribe en la base: exige la validación más estricta. Cierra opencode y pega este bloque después de listar_pedidos_por_estado:

// Tarea del estudiante 2: crear un pedido con validacion estricta.
server.tool(
  "crear_pedido",
  {
    cliente: z.string().min(1).max(50).describe("Nombre del cliente, no vacio"),
    total: z.number().positive().max(10000000).describe("Total en pesos, mayor que 0"),
    estado: z.enum(["pendiente", "enviado", "entregado", "cancelado"]).default("pendiente").describe("Estado inicial"),
  },
  async ({ cliente, total, estado }) => {
    const nombre = cliente.trim();
    if (!nombre) {
      return { content: [{ type: "text", text: "El cliente no puede estar vacio" }], isError: true };
    }
    const pedidos = await leerPedidos();
    const maxId = pedidos.reduce((m, p) => Math.max(m, p.pedidoId), 1000);
    const nuevo = { pedidoId: maxId + 1, cliente: nombre, total, estado };
    pedidos.push(nuevo);
    await guardarPedidos(pedidos);
    const texto = "Pedido creado: " + nuevo.pedidoId + " de " + nuevo.cliente + ", estado " + nuevo.estado + ", total " + nuevo.total;
    return { content: [{ type: "text", text: texto }] };
  }
);

Guarda con Ctrl + S, comprueba opencode mcp list, abre opencode y escribe:

Crea un pedido pendiente para Luis con total 50000 usando mi herramienta

Qué debes ver: una línea con caribemart_crear_pedido, la confirmación con el número nuevo (por ejemplo 1005) y el registro guardado en pedidos.json. Esa captura es tu evidencia 3 (evidencia-3-crear.png). Abre pedidos.json y confirma que el pedido nuevo está al final.

Prueba la validación: pide de nuevo Crea un pedido con total menos 100. Debes ver el rechazo de zod (Number must be greater than 0) y ningún registro nuevo. Eso demuestra la barrera.

Si no lo ves: si se guarda un total negativo, revisa que pegaste el bloque completo con z.number().positive().

Problemas comunes

Si algo falla, busca aquí en orden:

SíntomaQué hacer
PowerShell dice que la ejecución de scripts está deshabilitada (al usar npm) Escribe Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, responde S y repite el comando.
node o npm “no se reconoce como comando” Cierra PowerShell y abre uno nuevo (el PATH se actualiza al abrir). Si persiste, reinstala Node LTS.
opencode mcp list no muestra caribemart o dice desconectado Estás en C:\caribe\lab07\mcp-caribemart y npm install terminó. Revisa opencode.json del Paso 5.
El archivo se guardó como server.js.txt u opencode.json.txt En el Explorador: pestaña Vista → marca Extensiones de nombre de archivo y cámbiale el nombre.
El modelo responde sin llamar tu herramienta Verifica /mcps dentro de opencode y que el servidor está conectado; repite la pregunta exacta del paso.
Un modelo Free responde Free usage limit reached (límite) Espera unos minutos o elige otro modelo Free con /models.
El servidor falla con console.log o no conecta Busca console.log en server.js y cámbialo por console.error. En stdio, el log normal rompe el protocolo.
